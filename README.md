## Featured Project

### [TurnRPG – Turn-Based RPG Prototype](https://github.com/guilhermy-de-oliveira/TurnRPG-Prototype-React-JS)

A turn-based RPG prototype developed independently as the final project of a frontend programming course, using React, JavaScript, and Vite.

The project was designed as a modular foundation for developers interested in building and extending turn-based games.

**Key Features**

- Modular systems for damage handling, health recovery, and combat logic.
- Enemy AI with different behavior profiles and a fear mechanic.
- Game Jolt API integration for authentication and trophy unlocking.

**Technologies:** React · JavaScript · Vite · HTML5 · CSS3
